# Module 3 — Data Science & Machine Learning Labs

This directory contains the completed internship deliverables for Days 9–14.

## Deliverables

| Day | Topic | Notebook |
|---|---|---|
| 9 | NumPy Fundamentals | `numpy_lab.ipynb` |
| 10 | Pandas I | `pandas_explore.ipynb` |
| 11 | Pandas II | `data_cleaning.ipynb` |
| 12 | Visualization & EDA | `eda_report.ipynb` |
| 13 | Regression | `regression.ipynb` |
| 14 | Classification, Clustering & Mini-Project | `module3_ml_project.ipynb` |

## Libraries

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

## Running the notebooks

```bash
jupyter notebook
```

Open any `.ipynb` file and run the cells from top to bottom.

## Dataset choices

- Days 10–12 use a self-contained sales dataset so the notebooks do not depend on external downloads.
- Day 13 uses scikit-learn's California Housing dataset.
- Day 14 uses scikit-learn's Iris dataset.

## Skills demonstrated

- NumPy arrays, vectorization, broadcasting and linear algebra
- Pandas indexing, filtering, inspection and feature creation
- Missing-value handling, type conversion, GroupBy, pivot tables and merging
- Matplotlib/Seaborn visualization and EDA
- Train/test splitting and feature scaling
- Linear and polynomial regression
- MAE, MSE, RMSE and R²
- Logistic Regression, KNN, Decision Tree and Random Forest
- Accuracy, precision, recall, F1 and confusion matrix
- K-Means clustering and silhouette score
